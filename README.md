# GradeJournal

Интерактивный консольный журнал оценок студента на C# / .NET 8.

## Запуск в Rider

1. Открыть `GradeJournal.csproj` в JetBrains Rider.
2. Нажать Run (▶) / F5 **без аргументов программы**.
3. Пользоваться меню на русском языке:
   - добавить оценку;
   - список;
   - средний балл;
   - удалить;
   - выход.

Данные сохраняются в `grades.json` в рабочей директории запуска.
